# Upload instructions

Do not delete the repository or its Git history.

1. Open the existing repository in GitHub Desktop.
2. Copy the contents of this prepared folder into the local repository folder.
3. Allow the operating system to replace files with the same names.
4. Review the changed-files list in GitHub Desktop.
5. Commit with: `Prepare reproducible v1.0 research release`.
6. Push the commit.
7. Confirm that the GitHub Actions test finishes successfully.
8. Create release `v1.0.0` only after checking the public repository.
9. Archive that release in Zenodo without selecting a community during publication.

The exploratory notebooks and previous files are intentionally preserved. Do not delete every file through the GitHub web interface.
